Factory Inventory Management System

A full-stack demo for inventory tracking, order management, demand forecasting, and spending analytics across factory warehouses. Single-page Vue frontend backed by a FastAPI service serving in-memory mock data.

Vue 3 SPA FastAPI REST API In-memory JSON data No database

Data Flow

From a filter click to a rendered chart A representative read path: the user narrows the dashboard by warehouse, category, status, or time period.

User adjusts a filter
A selection in FilterBar.vue updates shared refs in the useFilters composable (Time Period, Warehouse, Category, Order Status).
View reacts and requests data
A watcher in the active view calls the matching method in api.js, passing the current filter values.
Axios issues an HTTP GET
Non-default filters are serialized to query params, e.g. GET /api/dashboard/summary?warehouse=East&month=Q3-2025.
FastAPI filters in memory
The endpoint runs apply_filters() and filter_by_month() over the in-memory lists — case-insensitive matching, 'all' skipped, originals never mutated.
Pydantic validates the response
Results are shaped and type-checked against models (InventoryItem, Order, …) via response_model, then returned as JSON.
Vue stores raw data in refs
The response is assigned to reactive refs (allOrders, inventoryItems, …) inside the view.
Computed properties derive the UI
Metrics, groupings, and SVG chart inputs are calculated in cached computed properties and rendered declaratively in the template.
